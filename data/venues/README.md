# Перевірений каталог футбольних майданчиків

Дата дослідження: 2026-10-31. Досліджено всі 51 міста з таблиці City.

`research-*.json` містять перевірені джерела, адреси, короткі докази,
відомий формат полів та окремі списки відкладених/відхилених кандидатів.
Перевірка вебджерела підтверджує опубліковані відомості, а не вільний час
чи домовленість про проведення конкретної гри.

## Статуси

- `rental-confirmed`: оператор або інше первинне джерело явно пропонує оренду.
- `amateur-use-confirmed`: первинні джерела підтверджують доступне аматорське використання; це не підтвердження комерційного бронювання.
- `existence-only`: підтверджено існування, але поточний доступ потребує уточнення.
- `missing` / `rejected`: недостатньо доказів, невідповідне місто, закриття або інші суперечності.

Числове `capacity` означає підтверджений підтримуваний формат гри/кількість
гравців. Це не глядацькі місця та не кількість одночасних ігор. Для джерел
із декількома форматами береться найбільший прямо вказаний. `null` означає,
що число невідоме; воно не підміняється оцінкою з розмірів поля.

Підтверджені доступні поля імпортуються також із `capacity: null`.
`existence-only` не потрапляє до активного каталогу. Невідомі значення
не замінюються на 0, 10 чи припущення з назви або розмірів.

Підтверджені адреса, джерело та дата перевірки переносяться у Venue.
Додаткові явно задані атрибути Venue: `latitude`, `longitude`,
`contactPhone`, `websiteUrl`, `totalFields`, `hasChangingRooms`,
`hasShowers`, `hasParking`; атрибути Field: `environment`, `surface`,
`hasLighting`, `lengthMeters`, `widthMeters`. Вони мають походити з
перевіреного джерела; імпортер не виводить їх із довільного тексту.
`environment`: `OPEN_AIR`, `COVERED`, `INDOOR`; `surface`:
`NATURAL_GRASS`, `ARTIFICIAL_TURF`, `PARQUET`, `RUBBER`, `HARD_COURT`, `OTHER`.

## Інструмент

З кореня репозиторію:

```sh
node packages/db/prisma/venue-catalog.mjs plan
node packages/db/prisma/venue-catalog.mjs audit
node packages/db/prisma/venue-catalog.mjs apply
```

`plan` працює без мережі та створює `import-ready.json` з підтвердженими
полями зі статусами `rental-confirmed` або `amateur-use-confirmed`. `audit` читає
каталог Railway production. `apply` додає підготовлені записи в Railway
production через наявний API контейнер і приватне з'єднання до Postgres.
Публічний доступ до БД не відкривається.

Імпорт використовує детерміновані ID, нормалізацію назв з урахуванням міста
та атомарну транзакцію з повтором конфліктів серіалізації. Назви зіставляються
після нормалізації в межах міста/комплексу. Неоднозначні збіги зупиняють
транзакцію. Наявні атрибути доповнюються лише замість `null`/`undefined`: відомі
значення, зокрема `false`, 0 та місткість, зберігаються. Неактивні поля
не активуються повторно. Користувачі, ігри та ролі не змінюються.

`packages/db/prisma/seed-catalog.mjs` містить спільні `buildCatalogPlan()`
та `importCatalog(prisma, plan)`. Seed і Railway utility використовують
однакові правила; для віддаленого виконання серіалізується та сама фабрика
`createCatalogRuntime()`. `seed.ts` більше не створює демонстраційні комплекси.
Обидва імпорти перебудовують план із `research-*.json`; `import-ready.json` —
знімок для перегляду, а не незалежне джерело ручних змін.

Шлях до дослідження обчислюється від розташування helper, незалежно від cwd.
Контейнер із seed повинен містити `data/venues` за тим самим шляхом від кореня
репозиторію (потрібен Docker `COPY data/venues ./data/venues`).

Офлайн-перевірки:

```sh
node --test packages/db/prisma/seed-catalog.test.mjs
pnpm --filter @app/db typecheck
```

Поточний план: 18 комплексів, 38 полів, із них 23 з невідомою
місткістю. Після міграції ці записи застосовані в робочій базі.

## Виконані операції

- Міграція необов'язкових характеристик застосована 2026-10-31.
  Спільний seed/import додав 9 комплексів і 23 поля та доповнив
  адреси/джерела/дати наявних 9 комплексів. Контрольний повтор не створив
  і не змінив жодного запису. Публічний API підтвердив 18 комплексів,
  38 полів і 23 невідомі місткості; демонстраційний Бернабеу відсутній.
- Початковий імпорт: 6 комплексів, 11 полів, 5 міст — Київ, Одеса,
  Полтава, Чернівці, Чернігів. Контрольне читання підтвердило ці записи.
- Другий імпорт: 3 комплекси, 4 поля — академія «Кривбас» у Кривому Розі,
  СК «Поділля» й ДЮСШ №1 у Хмельницькому. Загалом 9 комплексів,
  15 ігрових майданчиків у 7 містах. ДЮСШ-1-1/1-2 — позначення
  ігрових зон із календаря організатора; для незалежного одночасного
  бронювання потрібно уточнити оператора. Підтверджені формати манежу
  «Кривбасу» стосуються юнацьких змагань.
- На пряме прохання власника видалено тестовий «сантьяго бернабеу»
  у Запоріжжі, 1 поле, 4 тестові гри та 2 пов'язані сповіщення.
  Перед видаленням збережено локальну копію
  `/private/tmp/kopanka-bernabeu-backup-20261031.json` (доступ лише власнику).
- Записи решти міст не вважаються готовими лише через наявність
  історичної згадки про професійний стадіон.
