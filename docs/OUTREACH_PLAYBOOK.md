# Коротке залучення футбольної компанії

Ціль: організатор створив гру, переслав посилання у свою групу, гравці
зареєструвались і записались, компанія повернулась на наступну гру.
Погоджено під час пробної розмови з власником 2026-11-04. Довга переписка не є ціллю.

## Сценарій

1. Перше звернення: хто звертається, користь організатору й гравцям,
   одне посилання для першої гри. Три короткі речення.
2. Згода: реєстрація → «Стати організатором» → створити гру → переслати групі.
   Два речення; час, зал і формат людина задає у формі.
3. «У нас уже є Telegram-група»: група лишається для спілкування,
   Kopanka допомагає бачити склад і записуватись на матч. Запропонувати одну гру.
4. Гра створена: готовий текст запрошення всім гравцям із посиланням.
5. Складне питання: коротка відповідь моделі за перевіреними фактами;
   невідомі тарифи/зобов'язання — власнику. Відмова або завершення — зупинка.

Ніяких питань про назву університету чи точну адресу, якщо цього не потрібно
для відповіді. «9–11» не перетворюється на вигаданий формат матчу. Аматорський
футбол, футзал, команди, склад, воротар/польовий — доречний контекст; тренерські
лекції та новини професійних ліг до цього сценарію не входять.

## Переглянуті скіли

У стандартному curated-каталозі Skill Installer тематичних маркетингових або
футбольних скілів для цієї задачі не знайдено. Переглянуто відкриті SKILL.md
репозиторію coreyhaines31/marketingskills; глобальне встановлення не виконувалось.

- [cold-email, v2.2.1](https://github.com/coreyhaines31/marketingskills/blob/main/skills/cold-email/SKILL.md):
  стислий текст, доречна причина звернення, одна проста дія. Застосовано до
  Telegram; email-технічні налаштування та серії повторних холодних листів не переносились.
- [sales-enablement, v2.4.0](https://github.com/coreyhaines31/marketingskills/blob/main/skills/sales-enablement/SKILL.md):
  коротка відповідь на конкретне заперечення, лише перевірені твердження.
  Довгі sales/discovery-дзвінки й презентації не потрібні цьому продукту.
- [onboarding, v2.0.2](https://github.com/coreyhaines31/marketingskills/blob/main/skills/onboarding/SKILL.md):
  найкоротший шлях до першої корисної дії та вимірювання використання після signup.
  Для Kopanka корисна дія включає запис гравців, а не тільки реєстрацію організатора.

Також переглянуто community-marketing; для першого запуску окрему програму
спільноти не додавали. Перевіреного готового football-specific skill для цієї
задачі в переглянутих результатах не знайдено. Футбольна база обмежена фактичними
правилами й можливостями проєкту у CLAUDE.md та PRODUCT_PLAN.md.

Повні сторонні скіли не завантажуються у runtime промпт. Робоча адаптація —
`apps/outreach/src/playbook.ts`, стислий `productInstructions` і набір тестових
сценаріїв. Зміни тексту версіонуються, щоб перевикористання підготовленої
відповіді не приховало нову версію сценарію.

## Пілот і рішення за результатом

Перший пілот обмежений 10 схваленими контактами; пріоритет мають регулярні
організатори зі своєю групою. Звіт показує кількість контактів, відповіді,
агреговані реєстрації/ігри/записи, повторні ігри та витрати токенів. Тариф моделі,
якість груп і фактичні конверсії ще невідомі; прогнозів результатів немає.

Перевіряємо гіпотезу: короткий конкретний шлях до першої спільної гри приведе
до реального використання. Сам по собі пілот без контрольної групи не доводить
перевагу над іншим текстом. Якщо є відповіді, але немає записів, розглядаємо,
на якому кроці зупинилися люди, до збільшення кількості звернень. Сценарій
не змінюється самостійно після одиничної розмови; правки проходять review і тести.
