# Відновлення пароля

Реалізовано email-сценарій для всіх ролей акаунта: «Забув пароль?» на `/login`
→ `/forgot-password` → лист → `/reset-password` → вхід із новим паролем.
Автоматичного входу після скидання немає.

## Налаштування API

- `RESEND_API_KEY`: ключ надсилання Resend, лише в приватному середовищі API.
- `EMAIL_FROM`: адреса відправника на підтвердженому в Resend домені, наприклад
  `Kopanka <support@your-verified-domain>`; приклад не є готовою адресою.
- `APP_URL`: справжній HTTPS origin player web. URL береться з конфігурації,
  не з Host/Origin клієнта. HTTP дозволений лише для localhost у development.
- `TRUST_RAILWAY_PROXY=true`: лише коли API доступний через Railway HTTP edge,
  який встановлює `X-Real-IP`. Без цієї опції бюджет IP використовує адресу
  прямого з'єднання (за проксі вона може бути спільною для всіх відвідувачів).
  Не вмикайте довіру до цього заголовка для сервера з прямим публічним доступом.

Без повного налаштування пошти форма показує тимчасову недоступність, API запиту
повертає SERVICE_UNAVAILABLE незалежно від email. `auth.passwordRecoveryAvailable`
перевіряє конфігурацію, а не фактичну доставку.

Міграція `20261105160000_password_recovery` повинна бути застосована до старту API.
Docker CMD уже виконує `prisma migrate deploy`. Міграція не змінює існуючі паролі.
Для локальної перевірки SMTP-сервер не потрібен: тести підміняють лише HTTP-виклик
поштового постачальника.

## Поведінка та захист

- 32 випадкові байти, представлені 64 hex-символами; у БД лише SHA-256 хеш.
- Одне активне посилання на акаунт, строк 30 хвилин, одноразове атомарне використання.
  Новий дозволений запит замінює старе посилання; протягом 60 секунд повторний
  запит нічого не надсилає й не скасовує попереднього.
- Відповідь запиту однакова для наявного, невідомого й обмеженого за email акаунта.
  Поштовий виклик не затримує відповідь; короткі відмінності БД маскуються
  мінімальною затримкою 300 мс. Це не гарантія математично сталого часу під навантаженням.
- Бюджети в PostgreSQL, спільні для реплік/перезапусків: 3 запити на email за
  15 хвилин, 20 запитів на IP за 15 хвилин, окремо 20 спроб зміни на IP за 15 хвилин.
  Перевищення IP-бюджету повертає TOO_MANY_REQUESTS. Ключі — HMAC із JWT_SECRET;
  сирі IP/email в таблиці бюджетів відсутні. Прострочені записи прибирає scheduler.
- Email порівнюється без урахування регістру, лист надсилається на збережену адресу.
  Якщо старі акаунти мають адреси, що відрізняються лише регістром, автоматичне
  відновлення не вгадує потрібний акаунт і не надсилає лист.
- Новий пароль: 8–128 символів, латинська літера й цифра. Він хешується Argon2.
- Зміна пароля збільшує `User.sessionVersion`; усі старі JWT, включно з токенами
  до цієї міграції, перестають авторизувати запити. Звичайний запит листа
  не змінює пароль і не відкликає сесії. Інші акаунти не змінюються.
- Токен у fragment посилання, не в HTTP query. Сторінка забирає його в пам'ять
  і прибирає з адресного рядка; перезавантаження потребує повторного відкриття
  посилання з листа. GET та поштові перегляди не використовують токен.
- На сторінках відновлення не завантажуються GA4/Meta; reset має no-referrer
  та noindex. Токени й паролі не записуються у звіти або повідомлення помилок.

## Доставка та межі перевірки

Надсилання виконується у процесі API з таймаутом 10 секунд. Невдала доставка
пише лише загальну помилку в server logs; автоматичного повтору після невизначеного
результату немає. Durable email queue відсутня: рестарт процесу може перервати
надсилання. Користувач може запросити новий лист після cooldown з урахуванням
15-хвилинного бюджету. Прийняття Resend не доводить доставку в Inbox.

Перевірено локально: міграції з нуля, справжні API/БД/Argon2, невідомий email,
реальна адреса з іншим регістром, cooldown, прострочення, заміна посилання,
одночасне використання (лише одна успішна спроба), старий/новий пароль,
відкликання звичайних і legacy JWT, конкурентний ліміт спроб. Поштовий API
підмінений: реальні листи не надсилалися, доставку й телефонний UX треба
перевірити після налаштування підтвердженого відправника.
