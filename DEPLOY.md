# Deployment

Two hosts: **Render** (API + Postgres) and **Vercel** (Next.js web). Your part is
only logging in and connecting the repo — configs live in this repo.

## 1. API + Postgres → Render

1. Push to GitHub (done).
2. Render dashboard → **New +** → **Blueprint** → pick `EdPrys/football-with-Miha`.
   Render reads `render.yaml` and creates the **football-api** web service and the
   **football-db** Postgres, wiring `DATABASE_URL` automatically.
3. On first deploy the start command runs `prisma migrate deploy` (creates tables).
4. Copy the API URL (e.g. `https://football-api.onrender.com`).
5. (Optional) seed venues once from the Render **Shell**:
   `pnpm --filter @app/db exec tsx prisma/seed.ts`

`JWT_SECRET` is generated by Render. Set **`WEB_ORIGIN`** to your Vercel URL after step 2.

### Alternative: Railway / Fly.io (Docker)

Use `apps/api/Dockerfile` (build context = repo root). Set env: `DATABASE_URL`,
`JWT_SECRET`, `WEB_ORIGIN`. Provision a Postgres add-on for `DATABASE_URL`.

## 2. Web → Vercel

1. Vercel → **Add New Project** → import the repo.
2. **Root Directory:** `apps/web` (Vercel auto-detects the pnpm workspace and installs
   from the repo root, so `@app/api` types resolve).
3. **Environment variable:** `NEXT_PUBLIC_API_URL` = your Render API URL.
4. Deploy. Copy the Vercel URL and put it into the API's `WEB_ORIGIN` on Render (redeploy API).

## 3. CI

`.github/workflows/ci.yml` runs typecheck + tests + web build against a real Postgres
on every push/PR — no setup needed beyond having the repo on GitHub.

## Environment variables (summary)

| Var                   | Where | Notes                                       |
| --------------------- | ----- | ------------------------------------------- |
| `DATABASE_URL`        | API   | Postgres connection (Render provides it)    |
| `JWT_SECRET`          | API   | long random string (Render generates)       |
| `JWT_EXPIRES_IN`      | API   | e.g. `7d`                                   |
| `WEB_ORIGIN`          | API   | web URL(s), comma-separated; restricts CORS |
| `PORT`                | API   | injected by the host                        |
| `NEXT_PUBLIC_API_URL` | Web   | the API's public URL                        |
